## 📖 Sobre o Projeto

O **Coro Jovem Emanuel** é uma aplicação web criada para organizar e gerenciar os hinos a serem cantados pelo grupo de louvor da igreja que participo.
Antes, toda a organização era feita via WhatsApp, de forma desorganizada, sem separação de vozes ou solos. A proposta deste projeto é justamente resolver isso, permitindo:

* Cadastro de músicas e suas letras;
* Inclusão de iframes do YouTube para cada hino;
* Marcação de trechos por tipo de cantor (solo, todos, homens, mulheres etc);
* Atribuição de nomes aos solistas;
* Filtro de busca por nome das músicas;
* Gerenciamento por login (apenas admins podem cadastrar/editar/remover hinos ou definir os “hinos do dia”).
* Responsividade

Foi durante o desenvolvimento deste projeto que percebi minha dependência excessiva de assistentes como o ChatGPT. Essa experiência me motivou a parar e estudar a fundo o Node.js, culminando depois no meu segundo projeto: **Contato Total**.
